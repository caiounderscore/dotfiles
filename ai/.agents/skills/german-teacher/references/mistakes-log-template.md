# mistakes-log.md — German learning tracker

Portable file stored by default at `~/.agents/state/language/german-mistakes-log.md`.
Read it at the start of every session so the teacher can target recurring errors, then
update it at the end.

## How to use
- The teacher appends new errors after each session.
- `Count` increases each time the same error category repeats.
- Categories: `Akkusativ`, `Dativ`, `Artikelendung`, `Adjektivendung`, `Possessiv`,
  `Wortstellung`, `Trennbare Verben`, `Rechtschreibung`, `Satzbau` (natural building).
