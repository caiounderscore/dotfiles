# DaF kompakt neu A2 — course map (Lektion 9–18)

Grounding reference for the german-teacher skill. The learner's coursebook is
**DaF kompakt neu A2** (Klett, ISBN 978-3-12-676314-1), combined Kurs- und Übungsbuch.
The Kursbuch part is printed pages ~1–94; the Übungsbuch part continues from ~95.
Each Lektion ≈ 8 pages (Kursbuch) and ≈ 8 pages (Übungsbuch).

Use this to generate **unit-accurate** drills and mock tests. When the learner names the
Lektion(en) on the test, pull the exact grammar list below and build exercises that
mirror the Übungsbuch formats (see `test-prep-playbook.md`).

> The test mirrors the Übungsbuch. So practice the **grammar of the named units** in the
> **exercise formats of that book** — that is the whole strategy.

## How the grammar maps to the learner's weak points

- **Dativ/Akkusativ** → L9 (Dativergänzung, pronoun position), L10 (Wechselpräp.), L12 (Dativ verbs).
- **Article + adjective + possessive endings** → L9 (after ein-/kein-/mein-), L11 (after der-),
  L14 (dies-/welch-/jed-), L16 (Genitiv adjectives). This is the highest-yield cluster.
- **Word order** → L9 (Dat/Akk order), L11 (weil/dass → verb last), L15 (TeKaMoLo, indirect questions),
  L17 (Passiv word order).
- **Verb forms** → L12 (Präteritum), L16 (Konjunktiv II), L17 (Passiv).
- **Connectors / subordinate clauses** → L11 (weil/dass), L12 (wenn/als), L13 (seit/bis, deshalb…), L18 (wenn/als).

## Übungsbuch exercise formats (mirror these on the test)

1. **Ergänzen Sie** — complete endings/forms/articles in tables or in a dialogue/Lückentext.
2. **Bilden Sie Sätze (wie im Beispiel)** — build sentences from word cues.
3. **Schreiben Sie Sätze mit …** — transform/combine (e.g. two clauses → *weil*-sentence; Komparativ).
4. **Was passt wo? / Ordnen Sie zu** — sort words/phrases into categories or match halves.
5. **Tabelle ergänzen** — fill a declension / conjugation / Komparativ–Superlativ table.
6. **Dialog ergänzen** — complete a conversation with a given word box.
7. **Beschreiben Sie / Schreiben Sie einen Text** — short free production with Redemittel.
8. **Korrigieren Sie** — find and fix the mistakes (error-spotting).
